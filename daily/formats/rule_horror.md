# Format: rule_horror — "If X, do Y" horror (the Check the Radiator style)

## Shape
1. **Hook line = a rule** (first line, alone): *"If your reflection smiles before you do, leave the bathroom."*,
   *"Your cat grows to the size of whatever he's hunting. Tonight, he's seven feet tall."* It must make
   someone stop scrolling in the first 3 seconds.
2. **Grounding** (2–4 short lines): who, where, a precise time (*3:18 a.m.*), one wrong detail.
3. **Escalation by checks** — the character tests reality (questions, a phone call, counting, looking
   closer). Each check gives a small answer that raises the stakes.
4. **The tell** — one plain sentence that flips everything (*"Emma was an only child."*).
5. **Final sting** — the last line is a new threat, closer than before (*"The last pair was right behind
   him."*). End on it: no moral, no explanation. Optional final line *"Follow for part two."* only if the
   story really is a part one.

## Voice
Second person or a named third person (Daniel, Emma, Adam…). Calm, matter-of-fact narration.

## Title / caption
Title = the action of the rule (*Check the Radiator*, *Leave the Bathroom*).
